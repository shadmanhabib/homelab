# Network
The home network infrastructure is built using Ubiquiti UniFi equipment. The network gateway is the UniFi Dream Machine Pro (UDM-Pro), the USW-Pro-Max-24-POE is the main network switch. This section will provide a brief overview of the setup and configuration of the network including routing rules and services.

## Initial Setup
UniFi Gateways can be setup from the web or the UniFi mobile app. Setup throug the UniFi mobile app is reccomended.

See [How to Set Up UniFi](https://help.ui.com/hc/en-us/articles/4416276882327-How-to-Set-Up-UniFi) for detailed information.

## Usage
The network can be managed through the cloud web interface at [UniFi Site Mananger](https://unifi.ui.com) or the UniFi mobile app. In the event that the gateway does not have internet access, you can locally access the web interface via the gateway IP address. See [Understanding UniFi Cloud Architecture](https://help.ui.com/hc/en-us/articles/30319146145175-Understanding-UniFi-Cloud-Architecture) for more information.

## Maintenance

Software updates and backups are automatically managed by UniFi.
